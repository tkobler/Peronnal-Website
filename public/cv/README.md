# CV folder

The two PDFs in this folder are what the **Get in Touch** page serves:

| File | Download button |
|---|---|
| `cv-en.pdf` | "Download English" |
| `cv-fr.pdf` | "Français" |

## Updating your CV

Replace `cv-en.pdf` and/or `cv-fr.pdf` with your own PDF, keeping the exact
filenames, then commit them. That's the whole process — no build step, and
`typst` is not required.

Two things to keep in mind:

- **Commit the PDFs.** Files in this folder are tracked by git on purpose: the
  GitHub Pages deploy builds from the repository, so an uncommitted PDF would
  404 on the live site.
- **Keep the filenames.** The links are hardcoded in
  [ContactClient.tsx](../../src/app/contact/ContactClient.tsx) as
  `/cv/cv-en.pdf` and `/cv/cv-fr.pdf`. If you'd rather use other names, change
  them there too (also the `download="..."` attribute, which sets the filename
  the visitor's browser saves).

## Where these came from

They were previously generated by the Typst pipeline in [`cv/`](../../cv/) and
copied into `public/` on every `npm run cv:build`. That automatic copy is now
commented out — the site reads this folder directly instead. The pipeline still
works if you want it; see [SETUP.md §6](../../SETUP.md#6-cv-download).
